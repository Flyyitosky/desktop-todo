# 桌面待办

一个面向 Windows 的轻量桌面待办工具，支持桌面悬浮、系统托盘和本地数据保存。

## 已实现

- 新增、编辑、完成和删除待办
- 截止日期与高、中、低优先级
- 未完成、全部、已完成筛选
- 窗口置顶、最小化和拖动
- 关闭窗口后驻留系统托盘
- 托盘快速新增及单实例运行
- 自动保存任务、窗口位置和置顶状态

## 环境要求

- Node.js 22.12 或更高版本
- npm 10 或更高版本

## 开发运行

```bash
npm install
npm run dev
```

双击任务文字或点击铅笔按钮可以编辑；点击右上角关闭按钮会隐藏到托盘。

## 构建检查

```bash
npm run typecheck
npm run build
```

## 打包 Windows 安装程序

建议在 Windows 环境运行：

```bash
npm run dist:win
```

安装包会生成在 `release/` 目录。任务数据保存在 Electron 的用户数据目录中，不依赖服务器。
